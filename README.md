## Запуск

1. Распакуйте весь portable-архив в обычную папку с правом чтения. Запустите `DzhiggaTV.exe`; отдельная установка .NET не требуется.
2. Откройте **Настройки → Плейлисты** через шестерёнку в боковом меню и добавьте свой `.m3u` / `.m3u8` или URL плейлиста. После импорта выберите канал.
3. Подтвердите загрузку EPG.ONE при первом запуске либо откройте настройки телепрограммы. Основной источник предустановлен: `https://epg.one/epg2.xml.gz`.
4. Добавляйте каналы в избранное кнопкой ★. Контекстное меню канала позволяет переименовать его, скрыть, назначить категорию, логотип и программу.
5. Выбирайте группу каналов кнопкой **Категории**. Шестерёнка открывает настройки, в том числе раздел **Избранное и подборки** для управления подборками. Порядок каналов в избранном меняется перетаскиванием и сохраняется.

Левая навигация при запуске показывает только значки. Кнопка ☰ раскрывает названия разделов; у значков есть всплывающие подсказки.

Категория для взрослых скрыта по умолчанию, включая поиск и гид. Её можно включить в общих настройках и защитить PIN. Скрытые пользователем каналы можно вернуть через настройки.

Подключение EPG не изменяет адреса трансляций. При неуверенном совпадении откройте **Назначить телепрограмму** в контекстном меню. Ручное назначение имеет приоритет при обновлениях. Названия и число доступных аудиодорожек определяются текущим потоком.

Мини-плеер включается кнопкой в плеере или `Ctrl+M`, перемещается за видео и изменяет размер. Кнопка булавки включает или выключает закрепление поверх окон; она и кнопка закрытия появляются при движении мыши. Полный экран включается `F11`, `Alt+Enter` или двойным щелчком по видео. Плеер сохраняет один HWND видеоповерхности, а управление рисуется отдельным WPF-окном поверх видео; так решается ограничение WPF airspace без перезапуска трансляции при смене режима.

## Управление

| Клавиши | Действие |
|---|---|
| `F11`, `Alt+Enter`, двойной щелчок | Полный экран |
| `Escape` | Вернуться из полного экрана или мини-плеера |
| `Ctrl+M` | Мини-плеер |
| `PageUp` / `PageDown` | Предыдущий / следующий канал |
| `Backspace` | Быстрый возврат к предыдущему просмотренному каналу |
| `↑` / `↓` | Громкость |
| `←` / `→` | Перемотка архива на 10 секунд |
| `Ctrl+←` / `Ctrl+→` | Перемотка архива на минуту |
| `M` | Отключить / включить звук |
| `Space` | Пауза |
| `F` | Добавить / убрать активный канал из избранного |
| `Ctrl+F` | Поиск каналов |
| `C` | Список каналов поверх видео |
| `G` | Телепрограмма |
| `I` | Реальная статистика видеодвижка |

Горячие клавиши просмотра не перехватывают ввод в текстовых полях. Аудиодорожки, субтитры, устройство вывода, соотношение сторон, режим HDR и профиль буфера доступны через управление плеером и настройки.

## Данные и конфиденциальность

Пользовательские данные находятся в `%LOCALAPPDATA%\DzhiggaTV` (при проверочном запуске можно задать другой каталог аргументом `--data-dir`). SQLite хранит источники плейлистов, исходные каналы и пользовательские настройки в зашифрованных DPAPI-блоках текущего пользователя Windows. Логотипы кэшируются на диске отдельно. Полная копия базы привязана к учётной записи Windows; это не переносимый экспорт.

Экспорт настроек содержит избранное, подборки, порядок, скрытые каналы, переименования, категории и соответствия EPG. Адреса источников и трансляций, пользовательские URL логотипов, пароли и произвольные параметры не экспортируются. Приватные URL не записываются в штатные журналы приложения и libmpv.

ID канала определяется ID источника, исходным названием, группой и номером одноимённого дубля. Поэтому смена подписанного токена сохраняет настройки. Изменение исходного названия/группы или перестановка совершенно одинаковых дублей может потребовать повторного назначения. Обновляйте существующий источник вместо создания нового, чтобы сохранить его ID.

EPG загружается потоково; gzip и распакованные данные ограничены по размеру. Обновление базы происходит в одной транзакции. Ошибка сети, повреждённый XML или отмена сохраняют предыдущую программу. WAL позволяет читать старую программу во время импорта. Логотипы загружаются по мере появления каналов на экране и сохраняются между запусками.

## Сборка из исходников

Нужны Windows 11 x64, [.NET 10 SDK x64](https://dotnet.microsoft.com/download/dotnet/10.0), PowerShell и встроенный в Windows `tar.exe`. Скрипты используют `work\dotnet\dotnet.exe`, если локальный SDK существует, иначе `dotnet` из `PATH`.

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
.\scripts\test.ps1 -PlaylistPath 'C:\private\playlist.m3u8'
.\scripts\publish.ps1
```

Проверка приватного плейлиста включается только через `-PlaylistPath` или переменную `DZHIGGATV_TEST_PLAYLIST`. Тест читает файл на месте и не копирует адреса в проект. Без такого файла этот отдельный сценарий пропускается.

`publish.ps1` создаёт self-contained `win-x64` папку, ZIP и SHA-256 в `outputs`. По умолчанию путь — `outputs\DzhiggaTV-portable-win-x64`. Повторный выпуск укажите в новую папку через `-OutputDirectory`, например `outputs\DzhiggaTV-portable-win-x64-v2`. Скрипт сохраняет предыдущие выпуски. Для сборки папки без ZIP используйте `-NoZip`.

Скрипт `download-mpv.ps1` скачивает закреплённую [сборку shinchiro 20261018](https://github.com/shinchiro/mpv-winbuild-cmake/releases/tag/20261018), проверяет SHA-256 архива и DLL и помещает `libmpv-2.dll` в `native`. Требуется обычный x86-64 процессор; вариант x86-64-v3 не используется. Архив не содержит настроек IPTV.

Для выпуска подготовлен самостоятельный установщик `DzhiggaTV-Setup-x64.exe`. Он устанавливает приложение для текущего пользователя, создаёт ярлык в меню «Пуск» и по выбору — на рабочем столе. Администратор и отдельная установка .NET не требуются. Данные библиотеки хранятся отдельно. Удаление — по инструкции в установленной папке; автоматическая запись удаления Windows в этом варианте не создаётся.

Пересборка установщика из исходников после создания portable ZIP:

```powershell
.\scripts\build-managed-installer.ps1
```

Подробности: [docs/INSTALLER.md](docs/INSTALLER.md). Дополнительно сохранён вариант `scripts\DzhiggaTV.iss` для Inno Setup:

```powershell
.\scripts\build-installer.ps1 -CompilerPath 'C:\tools\InnoSetup\ISCC.exe'
```

Скрипт использует имеющийся [Inno Setup](https://jrsoftware.org/isdl.php) и не устанавливает компилятор в систему. Установщик размещает приложение в профиле пользователя, создаёт ярлыки и запись удаления. Личные настройки остаются при удалении программы. Автоматическая сборка установщика возможна только при доступном `ISCC.exe`.

## Структура

| Проект | Ответственность |
|---|---|
| `DzhiggaTV.App` | WPF, MVVM, темы, библиотека, гид, мини-плеер и отдельное окно управления |
| `DzhiggaTV.Core` | M3U, модели, SQLite, DPAPI, пользовательское состояние и экспорт |
| `DzhiggaTV.Services` | XMLTV/gzip, EPG.ONE, консервативный matching, сетевые ограничения и кэш логотипов |
| `DzhiggaTV.Player` | libmpv API, D3D11 HWND, дорожки, статистика, отмена старых запросов и переподключение |
| `DzhiggaTV.Tests` | Консольные воспроизводимые проверки без внешнего test SDK |

## Проверки и ограничения

Пройдены 24 проверки Core/Services, 14 проверок HTTP-загрузки и 6 проверок обновления EPG/логотипов в WPF. Ранее также выполнены 18 проверок настоящего libmpv и запуск WPF с H.264 720p / AAC, D3D11VA, полным экраном, мини-плеером, переключением двух дорожек и повторной загрузкой библиотеки. Реальный импорт подтвердил 3227 каналов / 12 категорий. В версии 1.0.1 полная загрузка с пустого профиля дала 3137 соответствий, 577664 передачи и 20 из 20 загруженных и отображаемых WPF логотипов первых проверенных строк. Подробные результаты и ручной план приведены в [docs/VERIFICATION.md](docs/VERIFICATION.md).

Воспроизведение приватных IPTV-потоков, HEVC/4K и качество HDR10/HLG пока не проверены. HDR и тональное отображение зависят от потока, GPU, драйвера, дисплея и режима Windows HDR. Выбор опции сам по себе не подтверждает активный HDR. Статистика показывает только значения, полученные от видеодвижка. Телеархив и запись не заявлены.

Состояние доступности EPG.ONE и его HTTPS/HTTP-переадресаций фиксируется в отдельной документации проверки источников. Версия 1.0.1 автоматически подключается к публичным зеркалам `epg.one` и `ru.epg.one`, включая HTTP самого сервиса. Для сторонних серверов сохраняется HTTPS; дополнительный флажок разрешает HTTP для пользовательских сторонних источников логотипов.
