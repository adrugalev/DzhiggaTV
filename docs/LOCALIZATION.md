# Языки интерфейса

В версии 2.1 Windows-приложение и DzhiggaTV Remote поддерживают русский, английский и упрощённый китайский. Русский используется по умолчанию, язык операционной системы не меняет этот выбор.

В Windows: **Настройки → Общие → Язык интерфейса**. Выбор сохраняется в локальном профиле (`ui.language`), применяется к открытым окнам без перезапуска воспроизведения. В Remote: **Настройки → Язык интерфейса**. Выбор сохраняется на данном телефоне. До собственного выбора Remote использует язык компьютера; после выбора языки устройств независимы.

Названия каналов, пользовательские подборки, категории провайдера, описания и другие данные EPG сохраняются в исходном виде. Поиск продолжает работать по исходному содержимому. Даты и числа форматируются согласно выбранному языку; для китайского интерфейса Windows используется системный шрифт Microsoft YaHei с резервными шрифтами.

## Ресурсы

`src/DzhiggaTV.Localization/Messages.json` содержит общий автономный словарь: русский исходный текст, английский `En` и китайский `Zh`. `Texts.T` переводит статическую надпись, `Texts.F` форматирует сообщение с аргументами. Параметры .NET, их индексы и форматы сохраняются во всех переводах. Для XAML используется `i18n:Loc` со стабильным идентификатором `Texts.IdForKey`.

Обновление открытых WPF-окон затрагивает только строки, созданные локализатором: происхождение отслеживается по ссылке на строку через `ConditionalWeakTable`, а не по совпадению содержимого. Редактируемые поля и тексты провайдера не переводятся. Язык HTTP/WebSocket-запросов хранится в отдельном асинхронном контексте и не меняет язык Windows или других устройств.

Перед сборкой и тестированием Remote скрипт `Web/scripts/locales.mjs` создаёт небольшой `Web/src/messages.json` только для используемых веб-интерфейсом надписей. Новые вызовы `t` должны использовать строковый ключ и сохранять параметры `{0}`, `{1}`.

Проверки: `scripts/test.ps1` (полнота словаря, параметры, изоляция запросов, защита пользовательских строк, переключение WPF) и `npm test` в `src/DzhiggaTV.Remote/Web` (переключение языков, сохранение выбора и непрерывность видео).
