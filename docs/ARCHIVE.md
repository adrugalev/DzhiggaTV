# Архив телеканалов — версия 1.5

В телепрограмме выберите день и прошедшую передачу. У доступной записи есть кнопка «Смотреть в архиве»; двойной щелчок по передаче запускает именно её. Для текущей передачи поддерживается просмотр с начала. «Прямой эфир» всегда открывает текущую трансляцию отдельно от выбранной записи.

Архив доступен только на каналах с соответствующими параметрами плейлиста. У пользовательского плейлиста `tvg-rec` задаёт глубину в днях: 0, 1, 3 или 7. Всего в проверенном плейлисте 1 034 канала с архивом, в том числе 340 с семью днями. Граница проверяется по точному моменту, а не только по календарной дате. Истёкшие и будущие передачи не запускаются вместо архива как прямой эфир.

В основном плеере есть шкала перемотки, кнопки «Дата и время» и «В прямой эфир». Шкала работает по клику, перетаскиванию и с клавиатуры: стрелки — 10 секунд, Ctrl + стрелки — минута. При отсутствии EPG можно открыть запись через выбор даты и времени. Все даты показываются в локальном часовом поясе; адрес провайдера получает UTC. Обычный запуск приложения возобновляет прямой эфир последнего канала.

Описание, прогресс и следующие передачи основного плеера относятся к выбранной записи; данные текущего эфира в библиотеке и «Мультиэкране» сохраняются независимо. Если у выбранного времени нет EPG, название явно обозначает просмотр архива, а будущие передачи не подставляются из другого дня.

Существующая загрузка полного XMLTV сохраняет неделю прошедших передач из EPG.ONE. Сам источник [указывает наличие программы на неделю назад и вперёд](https://epg.one/). Пустой день означает отсутствие данных источника; переход по времени остаётся доступен в пределах архива провайдера.

## Поддерживаемые адреса

- `tvg-rec` и старый `timeshift`: SIPTV shift, `utc` — начало записи, `lutc` — текущее UTC. Этот формат проверен на пользовательском провайдере.
- `catchup="shift"`, `catchup-days`.
- `catchup="default"` с полным `catchup-source`, либо `catchup="append"` с суффиксом. Поддержаны `{utc}`, `{lutc}`, `{utcend}`, `{duration}`, `${start}`, `${end}`, `${now}`, `${timestamp}`, `${duration}` и UTC-компоненты `{Y}`, `{m}`, `{d}`, `{H}`, `{M}`, `{S}`.
- `catchup="flussonic"`: ограниченный диапазон `index-<UTC>-<длительность>.m3u8`.

Основание форматов: [документация IPTV Simple](https://github.com/kodi-pvr/pvr.iptvsimple#catchup) и [Streaming API Flussonic](https://flussonic.com/doc/api/streaming/). Неподдерживаемые режимы, отключённый архив и недопустимые адреса не объявляются рабочими. Исходные URL и параметры подписи не переписываются; параметры времени добавляются только к запросу архива.

## Воспроизведение и проверка

Видео выводится через прежний HWND и libmpv без перекодирования. Если поток допускает позиционирование, используется точный native seek; для перехода до начала загруженного диапазона адрес архива открывается заново с нужной позиции. Сохраняются громкость, выбранное состояние звука и пауза. Запись ограничена запрошенным диапазоном; нормальное завершение не вызывает переподключение. Сетевые ошибки сохраняют обычные ограниченные повторы, позиция запоминается для повторного подключения.

Проверки: Core `CatchupTests`, настоящий libmpv в `src/DzhiggaTV.Player/SmokeTests`, а также `tests/DzhiggaTV.Archive.SmokeTests` с локальным HLS и отдельным новым профилем. Опциональный `--provider-playlist` проверяет один архивный новостной канал реального провайдера без вывода URL. Профиль рабочей установки не используется. Проверка интерфейса мышью включает шкалу, выбор вчерашнего дня, возврат в эфир и двойной щелчок по прошедшей передаче.
