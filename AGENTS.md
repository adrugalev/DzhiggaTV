# Выпуск установщика

После каждого выпуска оставляйте актуальный установщик в корне проекта под постоянным именем `DzhiggaTV-Setup-x64.exe`. Обновляйте этот файл только после успешной сборки. Копия для передачи в чате не заменяет установщик в папке проекта.

Оба скрипта сборки установщика должны обновлять эту копию, в том числе при использовании нестандартного пути выпуска. Проверяйте совпадение SHA-256 копии с результатом сборки. Бинарный файл не добавляйте в Git.

Основной выпуск для автоматических обновлений собирайте через `scripts/build-release.ps1`. Версия задаётся в `Directory.Build.props`; версия установщика и вложенного приложения должна совпадать. Рядом с установщиком сохраняйте `DzhiggaTV-Setup-x64.exe.sha256`. Публикация в GitHub выполняется только по запросу пользователя; порядок и требования к Releases описаны в `docs/UPDATES.md`.

Пользователь разрешил автоматическую сборку и публикацию Releases после загрузки исходников. Workflow `.github/workflows/release.yml` запускается при push в `main`, публикует только ещё не выпущенный номер после успешных проверок и не перезаписывает опубликованные версии. При изменении приложения повышайте версию и обновляйте историю; для одной инфраструктуры повышать версию приложения не нужно.
